# 公文格式示例

## 一、总体说明

这是一个自包含的转换示例，用于验证正文、层级标题、中西文混排和常见 Markdown 元素。Latin text, ABC and 2026 should use Times New Roman. 示例图片保存在仓库内，不依赖 Obsidian Vault 或网络资源。

### （一）格式目标

正文采用公文版式，并保留 Markdown 的语义内容。**加粗文字**和*斜体文字*在公文正文中统一回归正文样式。

### （二）列表

1. 有序列表转换为正文编号。
2. 第二项用于验证连续编号。
3. 第三项

- 无序列表第一级
  - 无序列表第二级
- 包含 Latin item 的较长列表项，用于确认内容换行后与第一行文字对齐，而不是与项目符号对齐。
- 第三项

### （一）表格

| 项目 | 说明 | Value |

$$
